# 📚 AI Study Assistant

A semantic search-based AI study assistant built with Python, Sentence Transformers, and Streamlit.

🚀 **[Try the Live Demo](https://ai-study-assistant-anu.streamlit.app)**

💻 **[View Source Code](https://github.com/anu21maj/AI-Study-Assistant)**

## Overview

The AI Study Assistant searches study notes and retrieves relevant information based on the meaning of a user's question. It uses sentence embeddings and cosine similarity to identify relevant notes.

## Features

* Semantic search using Sentence Transformers
* Similarity-based ranking of study notes
* Relevance filtering to reduce unrelated results
* Interactive web interface built with Streamlit
* Automated tests for note loading and search quality
